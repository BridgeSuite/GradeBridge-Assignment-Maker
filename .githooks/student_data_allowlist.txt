# Allowlist for the student-data guard (.githooks/student_data_guard.py).
#
# Every entry is an exception to rule S6 (no student data in any repository),
# so every entry carries a reason after '#', and every change to this file is
# a reviewed commit. An entry without a reason stops the guard (fail closed).
#
#   email <address or glob>        # reason          (G1; case-insensitive)
#   path  <rules> <glob>           # reason          (rules: G1..G6, comma list, or *)
#   commit <rules> <hash>          # reason          (a historical commit, 7 to 40 hex
#                                                     digits; its own findings under the
#                                                     named rules pass at pre-push only)
#
# Globs are fnmatch patterns on the repository path; '*' also crosses '/'.
#
# Phase B copy (11 November 2026): the address entries of the Record
# repository's allowlist, and no path entries beyond this file itself. A path
# entry for this repository is added only by a reviewed commit with its reason.
